## GitHub Pages
Upload these files to a repository. In Settings → Pages, choose Deploy from a branch, main, / (root), then Save. For a subfolder deployment preserve all files in the same directory. No build or dependencies are required.

## Google Sites
Create a Google Site. Add a title and introduction, then Insert → Embed → By URL and paste the published website URL. Publish the Google Site. Alternatively paste the contents of catalogue.html as publication text. Native Google Sites does not import an HTML ZIP as an editable site.
